# myProject01
## 이 프로그램은 MBTI 검사를 하는 콘솔 프로그램입니다. 
### 1. 자료 구조:

questions 리스트에 딕셔너리 형태로 질문, 보기(A/B), 그리고 각 보기가 어떤 유형에 점수를 주는지(A_type, B_type) 저장했습니다.

scores 딕셔너리로 8가지 지표의 점수를 누적합니다.

### 2.문항 구성 (12문항):

각 지표(EI, SN, TF, JP)마다 3문항씩 배정했습니다.

3문항이므로 무승부(동점)가 발생하지 않아 별도의 예외 처리가 필요 없습니다.

### 3.입력 처리:

input() 함수로 사용자의 입력을 받습니다.

upper()를 사용하여 소문자(a, b)를 입력해도 자동으로 대문자로 변환하여 인식합니다.

A나 B가 아닌 다른 키를 입력하면 다시 입력하도록 while 루프로 제어합니다.

### 4.결과 도출:

최종적으로 대립되는 두 지표(예: E vs I)의 점수를 비교하여 더 높은 쪽의 알파벳을 가져와 4글자 문자열(예: "ENFP")을 만듭니다.

미리 준비된 results 딕셔너리에서 해당 유형의 해설을 찾아 출력합니다.

이 코드를 실행하시면 터미널 창에서 바로 MBTI 검사를 진행해 보실 수 있습니다. 혹시 질문을 더 추가하거나, 결과를 파일로 저장하는 기능이 필요하시면 말씀해주세요!
